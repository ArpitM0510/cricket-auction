# Cricket Auction

Real-time IPL-style cricket auction.

- Maximum 10 teams
- Default purse ₹120 Cr
- Squad 18–25
- Maximum 8 overseas
- Timers 3/5/7/10/15/20/30 seconds
- Marquee Set 1 and 2, followed by category sets
- Acceleration rounds 10 → 5 → 3
- Three unsold rounds
- Upcoming / Sold / Unsold logs
- Player photo and batting/bowling information desk
- Host, team and spectator roles
- Render + Docker deployment

For automatic player-data synchronization, configure an authorized/licensed cricket-data provider in server/data/provider.json.
